# Money extraction evaluation

Generated by `python -m scripts.evaluate_ledger --replay` from the CC0 synthetic benchmark in `fixtures/receipts_benchmark/` and the recorded provider answers in `fixtures/recorded_cloud/ledger.jsonl`. Re-running it reproduces this file byte for byte.

**Privacy contract.** Every amount is replaced by a numbered placeholder (`[AMOUNT_1]`, ...) before a provider call; the recorder asserts that no amount from the email appears in the request, and the provider only answers which placeholder is the total. The real number is filled in locally.

- **dev**: cases the local rules were developed against (so the rules are expected to do well).
- **holdout**: cases written after the rules were frozen, in other phrasings, never used to change them.

- **Rules**: local-only mode, no provider.
- **Hybrid**: what production does when a provider is configured: the local detector first, then the provider picks the placeholder; the rules decide if the provider fails or answers invalidly.

**Merchant** means whoever was paid or refunded when the email names them (the shop in a UPI or card alert), otherwise the sender. The first recorded run showed the labels had used the sender for nine UPI and bank alerts (six dev, three holdout) where the provider correctly named the payee; the labels were corrected to this definition, never to match an answer. The local rules use the sender, so they now miss those cases.

Recorded answers: 96 (gemini `gemini-3.5-flash-lite`: 85, gemini `gemini-3.8-flash`: 11).

## Limits

- Synthetic receipts by one author; real merchants format receipts in many more ways.
- The detector is a keyword gate: a receipt with no transaction words, or an advert that uses them ("pay only ₹99"), can be misjudged before any provider sees it.
- One entry per email: an email listing several separate payments records only its total.
- Only amounts are hidden. Digits inside other text stay as written, so a coupon code like `TREAT150` can still hint at a ₹150 discount; order numbers, dates and IDs are sent like they are for classification (minimised as described in the privacy policy).
